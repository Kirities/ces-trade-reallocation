# 证据审计与编辑修正

[English version](../en/evidence-audit.md)

所提供的 23 页 PDF 是研究的概念起点，讨论贸易冲突、越南调整、比较优势、投资和国际合作。公开报告在推进这些问题的同时，修正证据与推论范围。以下页码均指该 PDF。行政性内容及相似度报告页面不是研究证据，未予转载。

| 原文位置 | 问题 | 本项目处理 |
|---|---|---|
| 第 8—9、12、16 页 | 2024 年金额分别出现约 1,143 亿、1,365.011 亿和 1,366 亿美元 | 统一为此次提取的 Census 美国进口序列：2024 年 **1,363.176 亿美元**。该版本的 **1,143.829 亿美元属于 2023 年**。1,365.011 亿可能来自更早版本，但原文未记录日期。 |
| 第 12 页 | 2024 年美国出口和逆差分别为 130.441 亿与 1,234.570 亿美元 | 提取值为 **130.683 亿**与 **1,232.493 亿美元**。视为数据核对问题，不据此推断不当行为。 |
| 第 8、13、18 页 | 将全部增长归因于冲突，或等同于对中国生产的逐一替代 | 改为描述性份额与精确会计分解，没有估计因果系数。 |
| 第 9—10 页 | 外资实际到位额归于泛化 CEIC 外资页面 | 在到位额、注册额和国际收支净流入口径及版本明确前，不继续使用。项目没有外资效应估计。 |
| 第 13—14 页 | 将投资迁移一概称为零和、投机且不产生新增价值 | 改为产能、就业、供应商联系、不确定性和本地价值获取等有条件渠道。汇总额不能区分这些机制。 |
| 第 14、17 页 | 电子产业投入及出口占比、三星生产份额和低生产率增长缺少充分资料 | 删除未经核实的点估计和企业叙事，使用世界银行一手报告支持范围更窄的升级讨论。 |
| 第 15—16 页 | 以资本形成流量支持资本存量比较；资本表混合 2021 年单位与 PWT 10.01 标注 | 撤下这些表格。投资流量不同于资本存量，重用前必须核对版本、变量、价格基准和原始行。[官方 PWT 页面](https://www.rug.nl/ggdc/productivity/pwt/pwt-releases/pwt1001?lang=en)仅作为核验起点，本项目未导入该数据库。 |
| 第 18 页 | 将“Reciprocal Trade Act”写成在实施的机制，并由指控推断普遍规避 | 删除未经核实的法律归属。区分第 301 条措施与独立原产地执法；不当行为需要具体案件证据。 |
| 第 13—14 页 | 将 17.5 作为适用于越南的一般外资标准 | [联合国目标文字](https://sdgs.un.org/goals/goal17)具体指向最不发达国家。广义资源动员对应 17.3，合作维度保留 17.6、17.9 和 17.10。 |
| 第 15、18 页 | 由要素丰富度或第三国出口收益直接得出全球福利结论 | 分开讨论比较优势、政策调整价格、国民收入与全球福利。模型只计算有条件的进口组合购买力变化。 |
| 第 19—20 页 | 重复链接、未完成标题与泛化机构首页 | 只保留与实际分析相关且已核对的紧凑参考书目，不补造缺失元数据。 |

## 证据类别

**实际观测：**45 条 Census 年度记录。**实际计算：**份额、指数、复合增长和分解项。**示意情景：**CES 结果、关税楔子、成本变化和国内增加值比例。**拟议研究：**产品层面因果评价与供应商层面升级研究。

没有增加合成历史观测。情景结果不是实测、置信区间或预测。没有宣称同行评议或外部批准。运行公开代码不需要私人原 PDF；公开提取数据、来源清单和引文提供数值复现路径。
