# 方法与数学定义

[English version](../en/methods.md)

## 1. 度量口径

令 $X_{Vy}$ 为年份 $y$ 美国自越南的名义商品进口额，$M_y$ 为美国商品进口总额。定义 $s_{Vy}=X_{Vy}/M_y$，中国份额同理。世界其他地区金额为 $M_y-X_{Vy}-X_{Cy}$。CSV 金额单位为百万美元；图表明确转换为十亿美元或百分比。差额从美国角度定义为出口减进口。核验允许不超过 0.11 百万美元的舍入误差。

跨越 $n$ 个年度间隔的复合增长率为 $(X_1/X_0)^{1/n}-1$。指数为 $100X_y/X_{2017}$。没有季调、平减、插值、缺失值填补或异常值删除。保留提取时的历史修订，不尝试重建早期数据版本。

## 2. 对称增长分解

由 $X_V=s_VM$ 得到精确的两期恒等式：

$$\Delta X_V=\bar{s}_V\Delta M+\bar{M}\Delta s_V,$$

横线表示起止两期的算术平均。市场项等于 $s_0\Delta M+\tfrac12\Delta s\Delta M$，份额项等于 $M_0\Delta s+\tfrac12\Delta s\Delta M$。这相当于两种先后分解顺序的平均，把交互项均分。

2017—2024 年，两项分别为 28,482.80 和 61,357.40 百万美元，合计 89,840.20 百万美元。份额项占总增长 68.30%。任何一项都没有被识别为因果效应。

## 3. 进口需求模型

三个差异化来源为 $i\in\{V,C,R\}$。基准支出权重 $w_i>0$ 来自某一校准年份，加总为一。基准价格均标准化为一。CES 进口组合定义为：

$$Q=\left[\sum_i w_i^{1/\sigma}q_i^{(\sigma-1)/\sigma}\right]^{\sigma/(\sigma-1)},\qquad \sigma>1.$$

生产成本乘数 $c_i>0$ 与非负假设从价关税 $t_i$ 形成到岸购买价格 $p_i=c_i(1+t_i)$。成本最小化给出：

$$D=\sum_iw_ip_i^{1-\sigma},\quad P=D^{1/(1-\sigma)},\quad s_i'=\frac{w_ip_i^{1-\sigma}}{D}.$$

固定含税支出 $E=100$ 时，不含关税的海关价值为 $B_i=Es_i'/(1+t_i)$，数量为 $q_i=Es_i'/p_i$，关税收入为 $T=\sum_it_iB_i$，因此 $\sum_iB_i+T=E$。成本乘数按生产者价格变化且完全传递处理，没有估计独立传递参数，也没有求解供给均衡。

基准设定 $t_i=0$、$c_i=1$，得到 $P_0=1$、$s_i'=w_i$、$Q_0=E$。原有价格与关税差异被吸收到基准权重中，因此新增假设关税应理解为相对标准化基准的楔子。对中国全部进口统一施加关税是有意简化，不能重现实际产品覆盖。

## 4. 购买力与财政核算

实际进口组合为 $Q=E/P$，百分比变化为 $100(1/P-1)$。按新价格购买基准组合所需补偿为 $CV=E(P-1)$，因为 $Q_0=E$。这是关税返还前、有条件的进口组合补偿变差，不是全经济福利。

关税收入没有返还进入 $E$。事后直接将税收加到支出会改变需求，需要重新确定预算闭合。因此本项目分别报告税收与补偿，不以两者相减宣称净福利效应。出口海关价值收入也不同于出口商利润或增加值。

## 5. 成本阈值

设越南关税为零，其他来源生产成本为一，中国关税为 $\tau$。越南收入等于基准时，$s_V'=w_V$。令 $r=1-w_V-w_C$，得到：

$$c_V^*=\left[\frac{w_C(1+\tau)^{1-\sigma}+r}{1-w_V}\right]^{1/(1-\sigma)}.$$

使用 2017 年权重、$\sigma=4$ 和 $\tau=0.25$，得到 $c_V^*=1.038639$，即成本提高 3.86%。这是模型的代数边界，不是越南实际成本冲击的估计。它以越南没有关税为条件；若越南被征税，海关价值收入与支出份额不再同比变化。

## 6. 国内价值代理量

假定比例 $\lambda\in\{0.25,0.50,0.75\}$ 时，定义 $A_V=\lambda B_V$。它是在假定国内含量比例下的保留价值核算代理量，没有测量投入产出系数、所有权调整、利润汇回或环境外部性。提高 $\lambda$ 不代表无成本的政策实验，相关成本仅被置于模型之外。实现中，该比例不会改变需求份额。

## 7. 参数设计及模型边界

笛卡尔网格包括 3 个校准年份、4 个弹性、3 个中国关税、2 个越南关税和 4 个越南成本，形成 288 组配置；增加 3 个国内含量假设后为 864 行。绘图脚本还在确定性细网格上计算成本曲线与边界，这些展示计算不构成新增观测或不确定性估计。

模型假定名义进口支出固定、来源间替代弹性一致、偏好不变、除外加成本变化之外的生产者价格完全弹性、关税完全传递，并将世界其他地区汇总。模型没有美国国内替代品、收入反馈、报复、投资动态、内生产能、投入网络或双边汇率。校准按构造匹配基期份额，不代表反应参数得到验证。敏感性范围既不是置信区间，也不是预测。
